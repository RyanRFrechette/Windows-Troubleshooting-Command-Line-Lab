# LinkedIn Post - Windows Troubleshooting Command Line Lab

I completed a small portfolio project called Windows Troubleshooting Command Line Lab.

The goal was to practice real Windows troubleshooting commands and document how they apply to remote IT support work.

The lab includes command outputs and notes for:
- ipconfig
- ping
- tracert
- nslookup
- systeminfo
- tasklist
- netstat

I also redacted private local system details before publishing, which was an important part of making the project portfolio-safe.

This project helped me practice gathering troubleshooting evidence, explaining command results clearly, and documenting support workflows in a way that would be useful for help desk or remote IT support roles.
