# ipconfig Notes

## Command
ipconfig /all

## What It Checks
Shows network adapter details, IP configuration, default gateway, DNS settings, DHCP status, and adapter information.

## Why Support Uses It
This command helps verify whether a Windows device has a valid network configuration and whether it is receiving the correct network settings.

## Common Issues It Helps Diagnose
- No IP address
- Wrong network adapter
- Incorrect DNS settings
- Missing default gateway
- DHCP problems
- VPN or Wi-Fi adapter confusion

## Example Support Use
If a remote user says they have internet or VPN issues, ipconfig helps confirm whether the computer has valid network settings before moving to deeper troubleshooting.

## Privacy Note
Local IP addresses, MAC addresses, DNS servers, and gateway details were redacted before publishing.
