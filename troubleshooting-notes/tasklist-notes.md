# tasklist Notes

## Command
tasklist

## What It Checks
Lists running processes on a Windows system.

## Why Support Uses It
Tasklist helps identify what programs and background processes are currently running.

## Common Issues It Helps Diagnose
- Too many running apps
- Hung processes
- High-resource apps
- Suspicious or unexpected processes
- Application not launching correctly

## Example Support Use
If a user says Outlook or Teams is slow, tasklist can help confirm whether those applications are running and whether many background programs are open.

## Privacy Note
Process lists were captured for lab purposes. No private files or user documents were included.
