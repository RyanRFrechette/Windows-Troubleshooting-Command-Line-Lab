# tracert Notes

## Command
tracert google.com

## What It Checks
Shows the path network traffic takes from the local computer to a destination.

## Why Support Uses It
Tracert helps identify where network traffic may be slowing down or failing between the user's device and a destination.

## Common Issues It Helps Diagnose
- Routing delays
- Network path failures
- ISP or upstream issues
- VPN routing problems
- High-latency hops

## Example Support Use
If a user can connect to some websites but not others, tracert can help show whether traffic is failing locally, at the ISP, or farther upstream.

## Privacy Note
