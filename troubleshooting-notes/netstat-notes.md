# netstat Notes

## Command
netstat -ano

## What It Checks
Shows active network connections, listening ports, remote endpoints, connection states, and process IDs.

## Why Support Uses It
Netstat helps support technicians understand active network connections and whether a system is listening on expected ports.

## Common Issues It Helps Diagnose
- Application connection issues
- Unexpected listening ports
- Stuck connections
- Remote access troubleshooting
- Process-to-network mapping using PID

## Example Support Use
If a remote desktop, web app, or VPN client is not connecting correctly, netstat can help confirm whether the computer has active network connections or listening services.
