# ping Notes

## Command
ping 8.8.8.8
ping google.com

## What It Checks
Tests basic network connectivity to another host.

## Why Support Uses It
Ping helps determine whether a computer can reach the internet or another system. Pinging an IP address tests basic connectivity. Pinging a domain name also tests whether DNS is working.

## Common Issues It Helps Diagnose
- No internet connection
- DNS failure
- Packet loss
- High latency
- Destination unreachable errors

## Example Support Use
If ping to 8.8.8.8 works but ping to google.com fails, the issue may be DNS-related rather than a total internet outage.

## Privacy Note
Public IP test targets are safe for documentation. Local addresses were redacted where applicable.
