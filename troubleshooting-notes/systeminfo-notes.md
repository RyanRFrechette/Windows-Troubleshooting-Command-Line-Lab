# systeminfo Notes

## Command
systeminfo

## What It Checks
Displays Windows system details including OS version, install information, hardware summary, domain/workgroup status, hotfixes, and boot time.

## Why Support Uses It
Systeminfo helps support technicians quickly understand the device environment before troubleshooting or escalating.

## Common Issues It Helps Diagnose
- Unsupported Windows version
- Missing updates
- Device inventory questions
- Uptime-related issues
- Hardware or OS mismatch

## Example Support Use
If a user reports repeated crashes or performance problems, systeminfo can help document the OS version, uptime, and patch level for the ticket.

## Privacy Note
Host name, owner, product ID, install date, boot time, manufacturer, and model details were redacted before publishing.
