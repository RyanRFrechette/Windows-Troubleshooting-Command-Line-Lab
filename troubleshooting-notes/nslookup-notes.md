# nslookup Notes

## Command
nslookup google.com

## What It Checks
Tests DNS name resolution by asking a DNS server to resolve a domain name.

## Why Support Uses It
Nslookup helps determine whether a domain name can be translated into an IP address.

## Common Issues It Helps Diagnose
- DNS server problems
- Incorrect DNS configuration
- Domain resolution failures
- Website name not resolving
- Internal company resource name issues

## Example Support Use
If a user can ping an IP address but cannot open websites by name, nslookup can help confirm whether DNS resolution is failing.

## Privacy Note
DNS server details and IP addresses were redacted where needed before publishing.
